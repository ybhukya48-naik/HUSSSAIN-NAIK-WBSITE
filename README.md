# New Hussain Naik Website

This is a newly developed standalone portfolio website built from provided official information and photos.

## Files
- `index.html` - main page markup
- `styles.css` - UI design and responsive styling
- `app.js` - content data and dynamic rendering

## Features
- Latest updates section with 2024 photos
- Automatic side-by-side scrolling photo gallery
- Past services timeline with year filter buttons
- Biography snapshot
- News and media highlights
- Mobile-responsive layout

## Run
Open `index.html` in any browser.
